## Introduction

[Vite](https://vitejs.dev) is a modern frontend build tool that provides an extremely fast development environment and bundles your code for production.

This plugin configures Vite for use with a Ugarit backend server.

## Official Documentation

Documentation for the Ugarit Vite plugin can be found on the [Ugarit website](https://ugarit.com/docs/vite).
